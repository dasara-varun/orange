# DS Milk World — Clean Menu CSV

This ZIP intentionally contains no images and no image references. It includes the cleaned menu data only.

The CSV contains 79 distinct menu items extracted from the public Swiggy listing, including categories, item names, short descriptions, serving sizes where published, regular prices, offer prices, customization status, vegetarian status, source details, and retrieval date. Separate 500 ml and 1000 ml products are retained as separate rows.

The `menu_source_url` column contains links to the menu source pages. No image URLs, image filenames, image columns, image index, image catalog, or image-related references are included.
